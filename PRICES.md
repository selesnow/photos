# Цены на сайте

Единственный источник цен — [prices.json](prices.json). Руками цены в `index.html` и `script.js` не правим.

## Как менять

**Через Telegram-бота** (основной способ): в личке с ботом команда `/prices`, затем раздел → позиция →
кнопки −10 / −5 / +5 / +10 или «✍️ Ввести число» → «✅ Опубликовать». Сайт обновится за 1–2 минуты,
бот напишет «✅ Цены обновлены».

**Вручную:** отредактировать `prices.json` и выполнить
```
python .github/scripts/apply_prices.py
```
Скрипт перепишет цены везде, где они есть на сайте. Проверка, что сайт соответствует файлу:
`python .github/scripts/apply_prices.py --check`. Тесты: `python -I .github/scripts/test_prices.py`.

## Как считается итог в калькуляторе

```
итог = цена типа съёмки + доплата за локацию + трансфер (если выбран) + доп. услуги
```

- **Эль-Гуна** добавляет доплату (`locations.el_gouna.surcharge`) к любой съёмке.
- **Трансфер** зависит от локации (`locations.*.transfer`).
- **Летящее платье:** в пакет входит одно платье, но только на локациях из `types.dress.dress_included_at`
  (сейчас только «Пустыня»). На остальных локациях калькулятор автоматически добавляет аренду платья
  по цене `extras.dress.price`. Чекбокс «доп. платье» — это второе платье, оно платное везде.

## Что обновляется на сайте

- title / og:title / twitter:title: «от $N» (минимальная цена съёмки);
- Schema.org: `priceRange` (от минимальной цены съёмки до максимума: съёмка + доплата + трансфер) и цены в `Offer`;
- карточки «Виды съёмок и цены»;
- калькулятор: через `data-price`, `data-transfer`, `data-dress-free` у кнопок и `value` у чекбоксов;
- метка «+$N» у Эль-Гуны и тексты FAQ про трансфер и платье (в HTML и в Schema).

Если правила в `apply_prices.py` не находят нужный фрагмент (например, переписали вёрстку), скрипт
остановится с понятной ошибкой, а не оставит старую цену молча.

## Как это устроено

`/prices` в боте → Cloudflare Worker (репозиторий tg-chat-worker) читает актуальный `prices.json` из GitHub,
копит правки в черновике → «Опубликовать» отправляет в GitHub событие `prices_update` с изменёнными позициями →
workflow `.github/workflows/prices.yml` запускает `update_prices.py` (проверка, запись `prices.json`,
`apply_prices.py`), коммитит и пушит. Откат любого изменения — обычный `git revert` коммита «Цены через Telegram».
